# EU Retail Analytics Platform

Architect-level, multi-source retail analytics platform.

## Stack
- Ingestion / orchestration: Apache Airflow
- Lake: MinIO + Delta/Parquet
- Transform: Spark + dbt
- Analytics DB: ClickHouse
- API: Hasura (GraphQL)
- BI: Apache Superset

## Domains
- Executive KPIs
- Sales performance
- Customer analytics
- Operations / fulfillment
- Product performance
